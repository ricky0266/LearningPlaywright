# Learning Playwright

This repository contains my learning journey and examples for Playwright automation.

## Structure

- **chapter_01_basics**: Basic concepts and setup for Playwright with JavaScript.
- **chapter_12_Multi_Dimension_Array**: Understanding Multi-Dimensional Arrays and Pattern problems.
- **chapter_02_Java_concepts**: Exploration of Java concepts (if applicable/planned).
- **chapter_13_Callback** to **chapter_15_Async_Await**: Asynchronous Javascript concepts (Callbacks, Promises, Async/Await).
- **chapter_16_OOps** to **chapter_17_OOPs_Inheritance**: Object-Oriented Programming principles in JavaScript.
- **chapter_18_Typescript** to **chapter_22_Typescript_PRIVATE_PROTECTED_PUBLIC**: Introduction to TypeScript fundamentals, Interfaces, Enums, Generics, and Modifiers.
- **chapter_23_Playwright_Fundamentals**: Fundamentals of the Playwright automation framework and test configurations.

## Getting Started

1. Clone the repository.
2. Install dependencies: `npm install`
3. Run tests: `npx playwright test`
